# DISKINFO

**Useful CLI tool for developers**

## Features

- 🚀 Fast and efficient
- 📦 Single binary, no dependencies  
- 🔧 Easy to use
- 🔒 Secure by design

## Installation

```bash
git clone https://github.com/simplestar-992/diskinfo.git
cd diskinfo
go build -o diskinfo .
```

## Usage

```bash
./diskinfo --help
```
