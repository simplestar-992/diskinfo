## Diskinfo

A useful command-line tool for developers.

### Installation

```bash
git clone https://github.com/simplestar-992/diskinfo.git
cd diskinfo
go build -o diskinfo .
```

### Usage

```bash
./diskinfo --help
```

---

## Quick Start

```bash
./diskinfo [command]
```
